# Final Audio Library

These are organised copies of the portfolio audio assets.
The named source clips and contact_audio folder are preserved.

## Folders

- character/page-songs: Page singing cues
- character/home-picture: Home portrait voice lines and bird sound
- keyboard: Letters, numbers, special characters and error sounds
- page-transitions: Paper-crunch transition
- stickers: Sticker interaction lines
- editing: Edit and Done Editing lines
- projects/add-project: Add Project lines
- projects/save-changes: Save Changes lines
- projects/screenshot-actions: Project screenshot-related lines
- projects/remove-project: Project removal lines
- projects/links: GitHub and Live Demo lines
- projects/dropdowns: Dropdown sound options
- resume/print-save: Resume print/save lines
- resume/content-editing: Add/remove content lines
- contact/send-note: Send Note lines
- contact/social-links: Email, GitHub and LinkedIn labels

Vue components have not been changed.
Review the audio contents before wiring up individual interactions.
